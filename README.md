# HomeBox

HomeBox 是一款运行在 Windows PC 上的**个人 / 家庭文件服务**：把电脑上的一个文件夹变成局域网内可访问的「家庭云盘」，手机、平板用浏览器即可浏览、上传、下载和搜索文件，还能像微信「文件传输助手」一样在手机和电脑之间互传文字、图片和文件。

图标与界面里的「NAS」均已更名为 HomeBox。

## 功能

- **文件管理**：浏览、上传、下载、新建文件夹、重命名、复制、移动、删除。
- **全文 / 文件名搜索**：在管理面板内按名称快速检索。
- **在线编辑**：在管理面板内直接编辑文本文件。
- **回收站**：删除的文件进入回收站，可一键清空。
- **隐藏文件夹**：管理员可把某些文件夹对访客隐藏，并在 Windows 中加上隐藏属性。
- **对话传输**：类似微信「文件传输助手」，PC 与手机之间互发文字、图片和文件；附件持久化保存，重启不丢。
- **聊天管理**：在管理面板按日期范围查询聊天内容与聊天文件，并可清空与某个对象的整个对话。
- **账号权限**：唯一的管理员（admin）+ 多个访客（guest），密码 bcrypt 加密存储。
- **外网访问**：可选开启 IPv6 外网访问，并用二维码 / 链接快速登录。
- **独立存储空间**：可基于 VHDX 创建并挂载独立的虚拟磁盘作为存储空间。
- **深浅色主题**：跟随系统或手动切换。

## 架构

- 后端：Go 标准库 `net/http`，单文件可执行程序 `nasd.exe`。
- 前端：内嵌静态资源（`go:embed`），无框架、无构建步骤。
  - 手机端：`internal/web/static/`（`/` 入口，适配 Safari）。
  - 管理面板：同目录下的 `admin.html`（本机 WebView2 窗口，`127.0.0.1:8380`）。
- 桌面端：托盘图标 + WebView2 管理窗口（`github.com/getlantern/systray`、`github.com/jchv/go-webview2`）。

## 目录结构

```
pc/
├── cmd/nasd/            # 入口
├── internal/
│   ├── config/          # 配置读写（nasd.json）
│   ├── server/          # HTTP 服务与 API（移动端 + 管理面板）
│   ├── chat/            # 聊天/文件传输的持久化存储
│   ├── files/           # 文件系统操作与路径校验
│   ├── thumbs/          # 图片缩略图
│   ├── desktop/         # 托盘图标 + WebView2 窗口
│   └── web/             # 静态资源嵌入
├── icon.svg             # 应用图标
└── go.mod / go.sum
```

## 构建

需要 Go 1.27+（Windows）：

```bash
go build -o nasd.exe -ldflags "-H=windowsgui" ./cmd/nasd
```

`-H=windowsgui` 让程序不弹出控制台窗口；去掉该参数可在控制台中看到日志。

`cmd/nasd/rsrc.syso` 内嵌了应用图标（Windows 资源），已随仓库提交，`go build` 即可直接带出 HomeBox 图标。如需更换图标后重新生成：

```bash
go install github.com/akavel/rsrc@latest
rsrc -ico icon.ico -o cmd/nasd/rsrc.syso
```

## 使用

1. 运行 `nasd.exe`（或安装包安装后运行）。
2. 首次启动会弹出向导，创建管理员账号并设置存储目录（即要共享的文件夹）。
3. 手机 / 平板连上同一局域网，浏览器打开管理面板中显示的局域网访问地址，或点击托盘菜单「打开手机访问链接」。
4. 托盘菜单可打开本机管理面板（`http://127.0.0.1:8380`）或退出服务。

运行时数据保存在：

- `nasd.json` —— 配置与账号（含密码哈希）。
- `nasd.log` —— 日志。
- 共享根目录下的 `.nas_chat/`、`.nas_trash/` 等 —— 聊天附件与回收站数据。

## 命令行参数

| 参数 | 说明 |
| --- | --- |
| `-root <目录>` | 指定共享根目录（未设置则读取 / 生成 `nasd.json`） |
| `-port <端口>` | 移动端监听端口（默认 8377） |
| `-headless` | 仅启动服务，不弹窗口（调试用） |

## 默认端口

- 移动端 / 局域网访问：`8377`
- 本机管理面板：`8380`
